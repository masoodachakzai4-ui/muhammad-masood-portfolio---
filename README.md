## How to Run Locally

### Prerequisites
- **Node.js** (v18 or v20+ recommended)
- **npm** (v9+)

### Steps
```bash
# 1. Install dependencies
npm install

# 2. Start the local development server (runs on http://localhost:3000)
npm run dev

# 3. Build for production verification
npm run build
```

## How to Deploy on Vercel

1. Sign in to [https://vercel.com](https://vercel.com) with your GitHub account (`masoodachakzai4-ui`).
2. Click **"Add New..." → "Project"** and import your `masood-portfolio` repository.
3. Verify the build settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **"Deploy"**. Within ~45 seconds, Vercel will publish your portfolio on a public HTTPS URL (and you can attach a custom domain anytime under **Settings → Domains**).
